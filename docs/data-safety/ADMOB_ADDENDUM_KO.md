## 확정을 막는 공식 자료

공식 기준은 [Google Mobile Ads Android 데이터 공개](https://developers.google.com/admob/android/privacy/play-data-disclosure)입니다. 해당 페이지와 SDK Index는 앞선 작업에서 승인 후 재시도까지 HTTP 403을 반환했습니다. 이번 작업에서는 같은 접근이나 별도 프록시 우회를 반복하지 않았습니다. 사용 가능한 도구에 웹 검색이 없고 로컬 패키지·캐시에도 공식 공개 원문이 없습니다.

과거 공개 안내가 진단 정보에 `crash logs, app launch time, hang rate, energy usage` 등을 들었다는 배경 지식은 있으나 현재 SDK에 대한 검증 증거는 아닙니다. 따라서 **비정상 종료 로그와 기타 앱 성능 데이터는 미확정·미선택**으로 남겼습니다. 이 빈칸은 수집하지 않는다는 결론이 아닙니다. 진단 한 항목만으로 SDK 신고가 완료되었다고 판단하지 않습니다.

필요한 자료는 위 공식 페이지의 **자동 수집·공유 표 전체와 목적·전송 보안 설명·버전 제한**이 함께 보이는 캡처 또는 저장 페이지 한 번입니다. 이를 확보하면 유형별 체크박스를 소유자에게 하나씩 묻지 않고 전체 CSV를 일괄 확정할 수 있습니다. 특히 비정상 종료 로그/기타 성능의 별도 유형, 모든 데이터 범주의 목적, 공유 예외, UMP/제한 광고의 선택권, UMP 자체 처리와 암호화를 함께 확인합니다.

## 코드와 SDK에서 확인한 범위

`google_mobile_ads 9.2.0`의 원본 `android/build.gradle`은 기본 Google Mobile Ads SDK `25.5.0`, UMP `4.0.0`을 선언합니다. 패키지 소스는 수집 데이터와 Play 유형별 대응을 공개하지 않으며 최종 배포 AAB의 의존성 검증을 대신하지 않습니다. 다른 중개 SDK/어댑터를 추가하면 그 공개 자료도 별도로 반영해야 합니다.

앱의 `lib/ads/google_mobile_ads_gateway.dart`는 `AdRequest(nonPersonalizedAds: true)`를 사용합니다. 사진·얼굴 특징·풀이 본문·풀이 ID·Firebase UID·이메일·구매 토큰을 광고 extras로 전달하지 않습니다. 동의 준비 후 SDK 초기화·요청을 진행하지만, 이는 SDK 자체의 식별자 수집이나 UMP 통신이 없다는 뜻은 아닙니다. 비개인 맞춤·테스트 광고·동의 화면만으로 수집/공유 없음 또는 전체 데이터 선택 수집을 신고하지 않습니다.

현재 CSV에 광고 포함 여부 질문은 없습니다. 광고 포함 응답은 Play의 별도 앱 콘텐츠 항목에서 최종 광고 기능에 맞게 확인해야 하며 이 파일로 변경할 수 없습니다. AdMob 설정·실제 광고 전환 안내는 [AdMob 설정 안내](../ADMOB_SETUP.md)를 참조하세요.
