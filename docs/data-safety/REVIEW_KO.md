# SOUL READER 데이터 보안 CSV 검토 초안

2026-11-02 작성. 앱 `com.soulreader.soul_reader`, 현재 소스 버전 `8.5.6+98`의 검토용입니다. 입력 파일은 [SOUL_READER_DATA_SAFETY_DRAFT.csv](SOUL_READER_DATA_SAFETY_DRAFT.csv)입니다. **현재 Play Console에서 내보낸 파일과의 호환성은 확인하지 않았으며, 가져오기·저장·제출은 실행하지 않았습니다.**

**CSV 가져오기는 기존 응답 전체를 대체하는 것으로 안내되어 있습니다. 먼저 현재 Console의 데이터 보안 응답을 CSV로 내보내 백업하세요.** 현재 내보내기 파일과 이 초안의 질문·응답 ID 및 질문 수를 비교하고, 새 질문이나 기존 응답이 있으면 현재 파일에 반영한 뒤 가져오세요. 가져오기 후 표시되는 응답을 소유자가 검토·수정하고 저장·제출 여부를 결정합니다. 이 파일은 승인 또는 정책 준수 보증이 아닙니다.

아래 일곱 유형은 모두 **수집됨**, **임시 처리 아님**으로 설정했습니다. 표의 공유 여부는 CSV의 별도 공유 선택값입니다.

| 데이터 유형 | 수집 선택권 | 공유 | 수집 목적 | 공유 목적 |
| --- | --- | --- | --- | --- |

| 구매 내역 | 선택 | 아니요 | 앱 기능, 계정 관리, 사기 예방·보안·규정 준수 | 없음 |
| 앱 상호작용 | 필수 | 예 | 앱 기능, 분석, 사기 예방·보안·규정 준수 | 분석 |

광고·마케팅, 맞춤설정, 개발자 커뮤니케이션 목적은 선택하지 않았습니다. 사진·얼굴 특징은 서버 전송 없이 기기에서 처리한다는 현재 검토 기준으로 별도 수집 유형에 추가하지 않았습니다. 이는 SDK의 사용·진단 정보 전송과 구분합니다.

## 소유자가 확인할 전제

- 이름·이메일·사용자 ID·구매 내역의 **선택** 응답은 Google 로그인과 구매 없이 무료 기능을 이용할 수 있다는 기준입니다. 로그인이나 구매를 선택하면 해당 기능에 필요한 데이터는 처리됩니다.
- SDK 관련 세 유형의 **필수** 응답은 현재 앱에 SDK 사용·진단 정보 전송을 끄는 별도 설정이 없다는 기준입니다. 실제 출시 빌드의 SDK 설정이나 동의 흐름이 다르면 수정해야 합니다.
- 앱 상호작용의 앱 기능·보안 목적은 유료 주제 선택과 서버 작업 횟수 관리 등을, 분석 목적은 ML Kit SDK 사용 정보를 반영했습니다. 진단은 분석, 기기 ID는 SDK 분석과 보안 식별 용도를 반영했습니다. 실제 SDK 설정·버전과 데이터 용도는 최종 출시 빌드 기준으로 확인합니다.
- SDK 세 유형의 **공유 예 / 공유 목적 분석**은 이 대화에서 확인한 Google ML Kit 데이터 공개 안내의 사용·진단 정보 전송을 보수적으로 신고한 값입니다. Google이 이 앱의 데이터를 독립적인 목적으로 사용한다는 사실을 확인했다는 뜻은 아닙니다. 서비스 제공자 예외 적용 여부를 확인하면 소유자가 최종 응답을 조정할 수 있습니다.
- 인증·구매 데이터는 기능 제공을 위한 처리자 이용 및 사용자가 시작한 로그인·구매에 관한 예외를 적용하여 **수집만** 선택했습니다. 이 예외가 실제 처리 관계와 Google의 정의에 맞는지 소유자가 확인합니다.
- 모든 유형의 **임시 처리 아님**은 인증·구매 기록 및 SDK 정보가 메모리에서 요청 처리 직후에만 사라지는 데이터라고 단정하지 않는 기준입니다. SDK 보관 기간을 새로 확인했다는 뜻은 아닙니다.
- 삭제 URL은 공개된 요청 안내 페이지입니다. URL 입력이 자동 삭제 기능을 의미하지 않습니다. 실제 본인 확인·삭제 처리는 [계정 삭제 운영 절차](../ACCOUNT_DELETION_RUNBOOK.md)를 따릅니다.

현재 앱 기능·타겟 연령·공개 URL의 기존 정리: [Play 등록 자료](../PLAY_REGISTRATION_PACKET.md). ML Kit 공식 데이터 공개 안내: <https://developers.google.com/ml-kit/android-data-disclosure>. 공식 안내의 실제 SDK 설정·수집 목적과 출시 빌드가 일치하는지는 소유자의 최종 검토 대상입니다.

## 템플릿 출처와 검증

Google이 관리하는 [Android Publisher API 명세](https://github.com/googleapis/google-api-python-client/blob/main/googleapiclient/discovery_cache/documents/androidpublisher.v3.json)는 데이터 보안 응답에 CSV를 사용하며, 최신 템플릿은 [공식 도움말의 CSV 내보내기 절차](https://support.google.com/googleplay/android-developer/answer/10787469#zippy=%2Cexport-to-a-csv-file)로 받도록 안내합니다. 이 작업 환경에서는 해당 도움말 본문에 접근하지 못했습니다.

이 초안은 다음 공개 커뮤니티 자료의 동일한 783행 템플릿을 데이터로만 읽어 작성했습니다. 외부 코드를 실행하지 않았습니다.

1. [공개 CSV 템플릿, 고정 커밋](https://github.com/sanikantv/data-safety-from-code/blob/11de88d19546c14bdfb74a2d10ac40e4ba659e37/skills/data-safety-from-code/template/data_safety_template.csv)

[커뮤니티 가져오기 안내](https://github.com/sanikantv/data-safety-from-code/blob/11de88d19546c14bdfb74a2d10ac40e4ba659e37/README.md)는 기존 응답 전체가 대체된다고 경고합니다. 일곱 유형만 담은 부분 파일을 기존 응답에 병합하는 방식으로 사용하지 않습니다.
