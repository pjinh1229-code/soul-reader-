Place the public Android Firebase configuration here as `google-services.json`.
Download it from the SOUL READER Firebase project's Android app after enabling
Google Authentication and registering the Google Play app-signing SHA-1.

The app validates its package/project and requires a Web OAuth client ID before
initializing sign-in. Missing configuration leaves sign-in and purchases disabled.
Do not put service-account credentials, private keys, passwords or access tokens
in this directory. This directory is bundled into the Android application.
